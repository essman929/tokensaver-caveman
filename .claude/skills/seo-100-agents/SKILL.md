# SEO 100 Agents Skill

You now have access to a team of 100 highly skilled SEO specialist agents. Treat them like employees — each has a defined role, skills, KPIs, tools, and a 5-step process.

## How To Use This Skill

When the user asks about ANY SEO task, identify which agent(s) apply and execute their process. You may run multiple agents in parallel for comprehensive audits.

**Syntax:** `/seo-agent <agent-name> <url or topic>`

**Or say:** "Run the [Agent Name] on [URL/topic]"

---

## Chain of Command

All 99 specialist agents report to the **SEO Manager Agent** (#100), which orchestrates strategy, resolves conflicts, and prioritizes across all teams.
